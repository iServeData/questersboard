How it works

QuestersBoard is where {{ community }} plans World of Warcraft events, keeps track of who's coming, and shares stories afterwards. You can use it on this site or with the community bot in Discord; both do the same things.

Getting started

  • Press Log in and sign in with Discord. You need to be a member of the {{ community }} Discord server.
  • The first time, Discord asks you to allow QuestersBoard to see your Discord name. That's all it asks for.
  • Upcoming events are on the home page and in the event channel in Discord. You can look around without logging in.

Your characters

  • Add the characters you play under My characters, or with /character add in Discord.
  • Pick the game edition, then the realm or ruleset, faction, race and class. Suggestions follow what you choose, and a pairing that can't exist in that edition is pointed out.
  • Set the roles you can play (for example tank, healer or damage). Events use these when you join.
    • {% if cfg["blizzard"]["enabled"] and cfg["blizzard"]["battlenet_link_enabled"] %}
  • Sync from Battle.net (on My characters) reads the characters on your Battle.net account once: ones you already have here are marked as verified and get their level updated, and you can tick the others to add them. QuestersBoard doesn't keep your Battle.net login, so sync again to refresh. WoW: Forever characters only show up from level 10, after you log out with them once.
    • {% endif %}
  • Click a character to change it. Some details lock once the character has been in an event, so past events stay accurate; you can add it again as a new character instead.

Joining events

  • Press Join on an event, here or on its post in Discord, and choose a character and role.
  • If there's a free spot you're in straight away. If it's full you go on the waitlist and move up automatically when someone leaves. Some events need a host to approve you first.
  • Tentative means "maybe": you're on the list but you don't take a spot. When you're sure, press Join on the post or I'm in on the event page.
  • You can only be in one event at a time. If two events overlap, you're told which one is in the way.
  • If a host moves an event to a new time before it starts, you're asked to confirm you can still make it. Once an event has started, extending it doesn't ask you anything.
  • Press Leave any time to give your spot to someone else.

Reminders and calendars

  • The bot sends reminders by Discord direct message before events you've joined. Make sure the server allows messages from members.
  • Under My events you can make a private calendar link for your phone or computer calendar. Keep it to yourself; you can switch it off at any time.
  • The public calendar on the WoW page lists every event, without anyone's names.

Hosting an event

  • Press New event (or use /quest create in Discord) and fill in the title, edition, time and the roles you need. It starts as a draft that only you can see.
  • Press Publish when it's ready. A post appears in the event channel with Join, Tentative and Leave buttons, and it keeps itself up to date.
    • {% set pdays = cfg["publishing"]["probation_days"] %} {% if cfg["publishing"]["open_to_all"] %}
  • Every member can publish their own events.{% if pdays %} If you joined the {{ community }} server less than {{ pdays }} day{{ "s" if pdays != 1 }} ago, your first events need a moderator's approval: press Send for publishing and a moderator checks your draft and publishes it. You get a Discord message when it's live.{% endif %}
    • {% else %}
  • Don't have the event-creator role? Press Send for publishing instead. A moderator checks your draft and publishes it, and you get a Discord message when it's live.
    • {% endif %}
  • If the start time passes while a draft waits for approval, it has to be moved before it can be published.
  • Add co-hosts by their Discord username. They can help run the event and are told when it changes.
  • On the day, press Organizer on the Discord post (or open the event here) to Start and later End the event. If it runs long you get one reminder, and you can extend it by 30 minutes.
  • Afterwards, mark who came and write the event's story for the Chronicle.
{% if th.enabled %}

Event chat

  • Each published event gets its own chat thread in Discord for the people taking part. Joining adds you to it; leaving takes you out.
  • Use it to plan, share where to meet and talk about the run. It closes about a day after the event.
{% endif %} {% if vc.enabled %}

Event voice

  • When a host presses Start, the event gets its own private voice channel in Discord.
  • Everyone signed up, the hosts and community staff can get in. Press Join voice on the event post to jump straight there.
  • When the event ends or is cancelled, the channel is removed. If it sits empty for {{ vc.empty_teardown_minutes }} minute{{ "s" if vc.empty_teardown_minutes != 1 }} after the planned end, it is removed too, and a host can open it again if the group is still playing.

Leaving an event

{% if vc.remove_on_leave %}

If you leave an event while it's running, you lose access to its voice channel and are taken out of it.

{% else %}

If you leave an event while you're in its voice channel, you can stay until you hang up. After that you can't get back in unless you join the event again.

{% endif %} {% if vc.guest_invites %}

Guest voice links

Met someone in the game you'd like to talk to? You don't have to get them to make a character and join the event first.

  • Anyone who can use the event's voice can get a guest link with /voice invite in Discord{% if vc.invite_dm == "hosts" %}. Hosts also get their link by direct message when the event starts{% elif vc.invite_dm == "everyone" %}. Everyone in the event also gets their link by direct message when it starts{% endif %}.
  • Send the link to the person you're playing with. They open it, sign in with Discord, and are added to the {{ community }} server if they aren't already in it. Then they can join the voice channel.
  • Each link works for up to {{ vc.max_guests_per_invite }} {{ "person" if vc.max_guests_per_invite == 1 else "people" }} and only while the event is running. When it ends, the link stops working and guests lose access to the channel.
  • Guests don't need a QuestersBoard account, a character or a signup. They stay in the Discord server afterwards unless they leave it.
  • Only share your link with people you're actually playing with. You're responsible for who you invite.
{% endif %}

Hosts and the channel

  • The host and co-hosts can manage who's in the event's voice channel with /voice kick (take someone out; they can come back if they still have access), /voice ban (take them out and keep them out until the event ends) and /voice unban.
  • These only work for the event they're running, and only while it's running. A ban ends with the event.
  • Hosts can't kick or ban the server owner, community admins and officers, or the bot. Co-hosts can't kick or ban the event's host.
  • Use these for this event's channel only. Anything bigger is for the community's moderators.
{% endif %}

Chronicle stories

  • After an event, the host and everyone who took part are invited to write their own story about it. You don't need to be added as a co-author to write one.
  • Answer a few short questions (the plan, what happened, best moments), write more if you like, and add screenshots.
  • Press Submit for review. A reviewer reads it before it's published; they can also ask for changes.
  • Every approved story about an event appears on the same Chronicle page, starting with the host's.
  • If you'd like to write together, the author can add co-authors from the people at the event.
  • Your character is only named in a story if you've said yes. You can change that per event, and stop being named in a published story at any time.

Privacy and Remove me

  • QuestersBoard keeps only what it needs to run events. The Privacy page explains what that is and how long it's kept.
  • Under My settings, Remove me deletes your QuestersBoard profile, characters and signups. It doesn't remove you from the Discord server or touch anything you've posted there.

Good to know

  • You need to be in the {{ community }} Discord server to log in, join events or write stories.
  • Only one WoW event can run at a time unless the community says otherwise, and you can only be in one event at a time.
  • Direct messages from the bot only reach you if your Discord settings allow messages from server members.
  • Stories are reviewed before they're public, so publishing isn't instant.
    • {% if vc.enabled %}
  • Voice channels exist only while an event is running.
    • {% endif %}
  • Questions or problems? Ask a host or an officer in Discord.
